# dsh-web-search-brave-local — provider Brave Search pour ctx.web (étude)

Contrat d'enregistrement (lu : @deepseek-ai/dsh-web, dsh-web-search-deepseek, dsh-tool-web 0.2.1-rc.2) :
1. Plugin Host = module ESM (`type: module`, `main: lib/index.js`) exportant `name` (nom du plugin pour le loader), `inject: ["web"]` (le loader Cordis injecte alors `ctx.web` dans le ctx), `Config` (z.object de @deepseek-ai/schemastery, champs `.volatile()` relus à chaque recherche via `.get()`) et `apply(ctx, config)` ; ctx vient du loader Cordis (services de `inject` + `ctx.get("credentials")`).
2. `apply` appelle `ctx.web.registerSearchProvider({ id, available(): boolean, async search({query, maxResults}, signal) → { content?, sources: [{url, title?, snippet?, publishedAt?}], truncated } })` ; id en doublon → WebError `WEB_DUPLICATE_PROVIDER` ; un disposer est retourné, libéré avec la fiber appelante.
3. Sélection résolue à l'exécution (jamais par ordre d'enregistrement) : id = `searchProvider` de la config du service `web` (ou env `$DSH_WEB_SEARCH_PROVIDER`) ; non enregistré → `WEB_PROVIDER_CONFIGURED_MISSING` ; `available()` faux → `WEB_PROVIDER_CONFIGURED_UNAVAILABLE` ; sans id : exactement un provider utilisable requis, sinon `WEB_PROVIDER_AMBIGUOUS` / `WEB_PROVIDER_UNAVAILABLE`.
- web_search (dsh-tool-web) appelle `ctx.web.search({ query, maxResults }, signal)` : maxResults = config `searchMaxResults` du plugin tool-web (défaut 8), le seam tronque `sources[]` et pose `truncated` ; timeout = `searchTimeoutMs` (défaut 30000) attaché au tool (`ToolDefinition.timeoutMs`) et transmis comme `signal` — jamais un argument du provider.
- WebError (dsh-web, étend HarnessError de dsh-llm) : `new WebError(message, code, { cause })` ; codes : WEB_DUPLICATE_PROVIDER, WEB_PROVIDER_CONFIGURED_MISSING, WEB_PROVIDER_CONFIGURED_UNAVAILABLE, WEB_PROVIDER_AMBIGUOUS, WEB_PROVIDER_UNAVAILABLE, WEB_PROVIDER_ERROR, WEB_ABORTED, WEB_PROVIDER_CREDENTIAL_MISSING.

API Brave Search — vérifiée le 2026-10-29 sur les sources officielles citées ci-dessous :
- Endpoint : `GET https://api.search.brave.com/res/v1/web/search` ; en-tête d'auth `X-Subscription-Token: <clé>` (requis) + `Accept: application/json`.
- Paramètres : `q` (requis), `count` (1..20, défaut 20, ne s'applique qu'aux résultats web — l'adaptateur borne maxResults à 20), `country` (défaut US), `search_lang` (défaut en), `ui_lang`, `safesearch` (défaut moderate), `freshness` (pd/pw/pm/py ou plage), `offset` (0..9).
- Réponse : `web.results[]` avec `title` (string), `url` (string), `description` (snippet), `age` (lisible) et `page_age` (ISO) — mappés vers url/title/snippet/publishedAt ; bloc `web` absent ou malformé → échec propre (WEB_PROVIDER_ERROR), `web.results: []` → tableau vide légitime ("No results found." côté tool). 401/403 → message sans la clé ; 429 → limite de débit ; cause réseau conservée.
- Sources : [documentation](https://api-dashboard.search.brave.com/app/documentation/web-search), [référence API](https://api-dashboard.search.brave.com/api-reference/web/search/get), [skill officiel](https://github.com/brave/brave-search-skills/blob/main/skills/web-search/SKILL.md) (liens présents sur les deux premières), [page produit](https://brave.com/search/api/).

Réglage de `searchProvider` : le bundle surcharge la ligne `web` de base (`id: web`, `@deepseek-ai/dsh-base/cordis.patch.yml` lignes 467-471) en restituant `config` en bloc (`searchProvider: brave`, `fetchProvider: http`) et insère la ligne `web-search-brave` — installé et vérifié live le 2026-10-29. Clé : référence `BRAVE_SEARCH_API_KEY` (config apiKeyRef, defaut) ou champ secret `apiKey`.

État (2026-10-29) : bundle installé par `plugin_manager install_bundle` (lien pnpm ; `pnpm install` exécuté une fois dans ce répertoire pour résoudre schemastery + peers) ; clé Brave enregistrée dans le coffre sous `BRAVE_SEARCH_API_KEY` (vérifiée par empreinte SHA-256) ; `web_search` réel testé avec succès via Brave (sources + publishedAt remontés).

INCERTAIN (résiduel) : limite de longueur de `q` divergente entre la référence API (600 caractères / 75 mots) et le skill officiel (400 / 50) — non contrainte par l'adaptateur ; forme exacte du corps d'erreur Brave hors 401/403/429 (l'adaptateur échoit 300 caractères du corps).
