## Quick Apply — architecture réelle (mise à jour 10/11, lot #124 ; détenteur socket = daemon depuis #130)

- **Canal actif unique : dispatch natif QTi.** L'app ReClaude (Claude Desktop re-signé, JS injecté dans l'asar) **ne tient pas le socket** : elle s'y connecte comme client relais (protocole `reprise-relay-1`, greeting relay, push `relay/dispatch`) vers `~/.claude-desktop/quick-entry.sock`, bindé par le daemon `claude-desktopd` (un seul socket ; l'ancien nom quick-entry-reprise.sock n'est plus créé). Méthodes exposées : `initialize`, `quick_entry/capabilities`, `quick_entry/submit` (`request_key` requis, `chatId` optionnel). Toute autre méthode → `-32601` (normal).
- **Le daemon `claude-desktopd` (`claude_desktop_quick.py`) est le détenteur requis du socket `quick-entry.sock`.** Un socket `connect()` refusé ou absent = daemon arrêté : le démarrer est la réparation normale. Le bridge MCP `claude-desktop` peut renvoyer `engine_unavailable` (« Endpoint Quick Apply injoignable ») alors que le socket répond : diagnostic par `connect()` direct + greeting avant toute conclusion, puis ouvrir ou compléter une issue sur le bridge. Ne pas contourner par un JSON-RPC `AF_UNIX` direct : il ne laisse aucun reçu durable (`dispatch_attempted` = fire-and-forget).
- `claude_desktop_apply.launch()` / `shutdown()` **refusent** (`return False`) : adoption d'un navigateur non possédé interdite tant que le lifecycle n'est pas implémenté.

## Faits techniques établis

- Le serveur Quick Apply **démarre SANS Claude Desktop** (il bind son socket seul) → pas de blocage d'ordre ; les soumissions sont livrées quand Desktop est prêt.
- Un **socket orphelin** (fichier présent, connexion refusée) = `stopped`, pas `running`. Vérifier par `connect()`.
- `native-install` ne relance l'app **qu'avec `--open`** (compiler ne perturbe pas la session).
- Les timestamps de l'UI sont en **heure locale 24h** (helpers `localTime`/`localDateTime` dans `Dashboard.swift`).
- `runtime.terminate()` doit être résilient (un `killpg` refusé ne doit pas écraser le retour de l'appelant) — corrigé, source du bug des quotas manquants.
